# BaytiNet - تطبيق مراقبة استهلاك الواي فاي

تطبيق Flutter مخصص لنظام أندرويد يقوم بحساب وعرض كمية استهلاك بيانات الواي فاي.

## الميزات:
- **مراقبة دقيقة**: يستخدم `NetworkStatsManager` للحصول على بيانات دقيقة من النظام.
- **عمل في الخلفية**: خدمة (Foreground Service) تعمل باستمرار لضمان تحديث البيانات حتى عند إغلاق التطبيق.
- **التشغيل التلقائي**: يبدأ التطبيق بالعمل تلقائياً فور إعادة تشغيل الهاتف.
- **رسوم بيانية**: عرض الإحصائيات (يومي، أسبوعي، شهري) باستخدام رسوم بيانية عصرية.
- **دعم كامل للغة العربية**: واجهة مستخدم كاملة من اليمين إلى اليسار.
- **وضع مظلم وفاتح**: إمكانية التبديل بين السمات بسهولة.

## كيفية التشغيل:
1. قم بفتح المشروع باستخدام **Android Studio**.
2. تأكد من تثبيت Flutter SDK.
3. قم بتوصيل هاتف أندرويد أو تشغيل محاكي.
4. قم بتشغيل التطبيق (`flutter run`).
5. عند التشغيل الأول، اتبع التعليمات لمنح إذن "الوصول إلى بيانات الاستخدام".

## ملاحظة حول المعاينة:
بسبب الاعتماد على ميزات أندرويد الأصلية، لا يمكن معاينة التطبيق بالكامل عبر الويب. يرجى تشغيله على بيئة أندرويد لرؤية الواجهة والبيانات الحقيقية.
