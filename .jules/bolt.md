## 2025-01-24 - [SQLite Performance Optimization in Flutter]
**Learning:** Default SQLite configurations in Flutter (sqflite) are optimized for data integrity over speed. Enabling WAL (Write-Ahead Logging) mode and setting synchronous to NORMAL can significantly improve write performance and allow concurrent reads while the database is being written to (e.g., by a background service). Adding indexes on columns used in WHERE clauses and ORDER BY is critical as the dataset grows to avoid linear degradation of performance.
**Action:** Always enable WAL mode and synchronous=NORMAL in `onConfigure` for performance-critical apps, and proactively index columns used for range queries or frequent filtering.
